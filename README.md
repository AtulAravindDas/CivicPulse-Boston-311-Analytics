# CivicPulse: Boston 311 Service Request Analytics Dashboard

CivicPulse is an interactive Tableau dashboard built using Boston 311 service request data to analyze public service operations, department workload, SLA compliance, overdue requests, and geographic request hotspots across Boston.

## Dashboard Preview

![Dashboard Preview](screenshots/Dashboard_Preview.png)

## Project Objectives

- Analyze daily service request trends
- Identify top service request categories
- Compare department-level request volume
- Visualize request hotspots across Boston
- Evaluate on-time vs overdue request completion
- Identify service categories and departments with the highest overdue cases

## Tools Used

- Tableau
- Boston 311 Open Data
- Data Cleaning
- Geospatial Analytics
- SLA / Operational Performance Analysis

## Key Insights

- Domestic Animal Issues and Street Light Outages were among the highest-volume service request categories.
- Animal Care & Control, Public Works, and Parks & Recreation handled the largest request volumes.
- Street Light Outages accounted for the highest number of overdue cases.
- Public Works had the highest overdue request volume among departments.
- Around 37% of requests were overdue, indicating meaningful SLA compliance challenges.

## Dataset

Data source: Boston 311 Service Requests from Analyze Boston.
